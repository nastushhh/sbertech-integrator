# phonebook application

Программа реализует телефонный справочник с динамическим обновлением записей.

## Описание

- Хранит в памяти 100 000 записей (имя и номер телефона).
- Каждые N миллисекунд (500 < N < 5000) обновляет номера у случайного числа записей.
- Через T секунд (60 < T < 300) с момента запуска выводит в консоль записи, которые не изменялись M секунд назад (0 < M < 30).
- После вывода записей программа завершает работу.

## Требования

- **Java**: 17
- **Maven**: 3.6.0 или выше

## Тесты

Проект включает юнит-тесты, написанные с использованием JUnit 5, чтобы проверить ключевые компоненты программы. Всего реализовано 10 тестов, которые покрывают:

- **PhoneRecord**: Проверка создания записи, работы геттеров/сеттеров и формата строки (`toString`).
- **NumberGenerator**: Проверка на формат номера телефона `+7-XXX-XXX-XX-XX` и его уникальности.
- **RandomUtil**: Проверка диапазонов случайных значений: N (500–5000 мс), M (0–30 сек), T (60–300 сек).
- **PhoneBookService**: Проверка инициализации справочника с 100 000 записей.

Для запуска тестов выполните команду:
```bash
mvn test
